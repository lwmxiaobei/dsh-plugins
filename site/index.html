02 / Install guide

如何安装 DSH 插件

目录提供跟随上游默认分支的命令，运行时获取最新版本。安装前仍应阅读上游说明并确认插件权限。

  1. 01

    查找插件

    使用名称、功能、包名或仓库作者搜索，也可以按开发语言和许可证缩小范围。

  2. 02

    检查详情

    打开插件详情页，核对仓库、当前包版本、许可证、最近更新时间以及目录校验快照。

  3. 03

    复制并运行

    点击复制安装命令，在 DeepSeek Harness 所在终端运行。安装后按照上游文档完成配置。

03 / Directory policy

目录如何维护

DSH Plugins 从 GitHub 的 dsh-plugin 主题发现候选仓库，并校验插件清单、包信息与安装条件。目录定时同步公开数据，详情页明确标注数据更新时间。

收录不等于安全审计或官方背书。我们保留原始仓库链接，不生成虚假评分，也不会把未知许可证标记为可自由使用。发现信息有误时，可通过 GitHub 提交问题或修正。

04 / FAQ

常见问题

关于搜索、安装命令和目录数据的说明。

DeepSeek Harness 插件是什么？

它是安装到 DeepSeek Harness 的扩展包，可以增加工具、界面、模型接入、记忆、浏览器自动化等能力。每个插件由对应上游仓库维护。

安装命令会安装哪个版本？

命令不包含提交哈希，DeepSeek Harness 会在安装时获取上游默认分支的最新版本。详情页中的提交信息仅用于标记目录校验快照。

目录中的插件都经过安全审计吗？

没有。目录只校验公开元数据与基本插件结构，不代表对代码、安全性或隐私实践的完整审计。安装前请自行查看源码、权限和许可证。

如何提交或更新插件？

为公开 GitHub 仓库添加 dsh-plugin 主题并确保插件清单完整。目录同步后会重新发现和校验，也可前往项目仓库提交问题。

社区维护，不代表官方背书或安全审计。
